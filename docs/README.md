# Docs and design artifacts

This directory keeps reference material and unused design assets out of the
application source tree. Nothing here is included in the built app.

- `lane-relations-v2.html` — an old visual/architecture mockup kept for
  reference; it is not a runtime file.
- `welcome-embed-0.webp` — an unused welcome illustration.
- `workbuddy-robot-square.png` — an unused third-party brand image.

The images in `desktop/assets/` are the files actually shipped with Lane.
Third-party names, logos, and trademarks remain the property of their owners;
see the project `DISCLAIMER.md` and `THIRD_PARTY_NOTICES.md`.
